A note for grown-ups

Inspired by collecting objects by likeness and sorting everyday objects. Each mode has 120 different puzzles, served as six-puzzle trails: 20 plays per mode before puzzles repeat. There are 51 kinds of pictures, with different colors, sizes, shapes, patterns, and uses. Familiar rules return with different objects, so children practice noticing instead of memorizing a picture or button position.

Your browser remembers which puzzles it has dealt, including after refreshes. After all 120 puzzles in a mode have been dealt, that mode starts a newly shuffled deck. Clearing browser data resets this history.

Read object names together, or use the speaker button for prompts and choices when your browser supports speech. Ask your child to describe what they see before reading the choices. The choices use one intended rule, but a different explanation can be thoughtful too. Ask “What makes you think that?” and use “We found another way!” to discuss an alternative and move on. There are no lost points or time limits.

Keep exploring away from the screen: collect safe household items, sort them two ways, and invite your child to invent a rule for you to guess.
